TIENDA 5 ESTRELLAS - UNIDAD 4
================================

Contenido:
- index.html: inicio con carrusel Bootstrap.
- productos.html: catálogo responsivo, búsqueda, tarjetas, modal y carrito de demostración.
- nosotros.html: información del negocio, acordeón FAQ y modal del equipo.
- contacto.html: formulario con validación del lado del cliente.
- css/estilos.css: personalización visual.
- js/main.js: eventos DOM, búsqueda, carrito, AOS, SweetAlert2 y validación.
- img/: imágenes originales del proyecto.

Cómo ejecutar:
1. Descomprime esta carpeta.
2. Abre la carpeta en Visual Studio Code.
3. Ejecuta index.html con Live Server (recomendado) o ábrelo en un navegador.
4. Se requiere conexión a Internet para cargar Bootstrap, Bootstrap Icons, SweetAlert2 y AOS desde sus CDN.

Notas:
- Los precios son marcadores y deben reemplazarse por los precios reales.
- El carrito y el formulario son demostraciones del lado del cliente; no guardan pedidos ni transmiten mensajes a un servidor.
- El proyecto conserva el negocio y las imágenes del ZIP original, y amplía la maquetación para la Unidad 4.
